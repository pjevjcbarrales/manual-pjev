09.1.5

Permisos de Carpetas y Matriz de Control de Acceso (ACL)

Configuración de seguridad y gobernanza de acceso a carpetas, expedientes y series archivísticas del CGCA. Establece qué roles o usuarios tienen facultades para consultar metadatos, visualizar en línea (streaming), descargar binarios originales o testados, adjuntar, sellar o eliminar documentos.

Pendiente de desarrollo Seguridad y Gobernanza (DOC-08) LGTAIP / LGPDPPSO / IVAI Matriz ACL Granular
🔒 Separación Estricta: "Solo Lectura" vs "Permiso de Descarga"

Uno de los mayores riesgos en la gestión documental es la fuga de información confidencial. Para evitarlo, el sistema implementa la filosofía Zero-Trust de DocuWare:

1. Solo Lectura en Pantalla (Streaming): El usuario puede hojear y revisar el documento en el visor web interactivo, pero se le aplica una marca de agua diagonal semitransparente con su nombre de usuario, fecha, hora e IP, bloqueando la descarga del archivo binario a su computadora local.

2. Permiso Explícito de Descarga: Solo los roles autorizados (titular del área productora, auditor facultado) pueden extraer el PDF/XML original a disco local.

1 Descripción General

El módulo 09.1.5 Permisos de Carpetas y Matriz ACL define los privilegios granulares aplicables a las carpetas y expedientes institucionales. Resuelve las políticas de acceso bajo una matriz multidimensional:

Privilegio Código ACL Efecto en la Interfaz y en el Backend
Ver Metadatos VER_METADATOS El expediente aparece en la lista y resultados de búsqueda con sus datos generales (proveedor, monto, folio), pero sin acceso a ver el contenido de los archivos.
Visualizar en Pantalla VER_STREAM Permite abrir el visor web universal en modo solo lectura. El backend sirve el archivo vía streaming temporal en memoria y aplica marca de agua institucional.
Descargar Original DESCARGAR_ORIGINAL Habilita el botón "Descargar Archivo Original". Permite bajar el archivo binario auténtico tal como fue cargado al repositorio.
Descargar Versión Pública DESCARGAR_PUB Permite descargar únicamente la versión testada (con rectángulos negros sobre datos personales) aprobada por el Comité de Transparencia (IVAI).
Subir / Anexar SUBIR_DOCS Habilita la zona Drag & Drop y el botón "+ Adjuntar Archivo" en los formularios y en la bandeja de entrada.
Estampar Sellos ESTAMPAR_SELLOS Muestra la paleta de sellos oficiales autorizados para el rol del usuario (Revisión Conforme, Autorizado Pago, Pagado, etc.).
Versionar / Sustituir VERSIONAR Permite cargar una nueva versión correctiva de un archivo, obligando a justificar el motivo del cambio en la bitácora inmutable.
Administrar Carpeta ADMIN_CARPETA Facultad para modificar la matriz de permisos de la carpeta y autorizar transferencias o dictámenes de baja.

3 Stored Procedures Canónicos
-- SP 1: archivos.fn_leer_permisos_carpeta
CREATE OR REPLACE FUNCTION archivos.fn_leer_permisos_carpeta(
    p_filtros JSONB DEFAULT '{}'::jsonb
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = archivos, public
AS $$
DECLARE
    v_cgca VARCHAR(50);
    v_rol VARCHAR(50);
    v_resultado JSONB;
BEGIN
    v_cgca := p_filtros->>'cgca_codigo';
    v_rol := p_filtros->>'rol';

    SELECT COALESCE(jsonb_agg(row_to_json(r)), '[]'::jsonb)
    INTO v_resultado
    FROM (
        SELECT 
            p.id_permiso,
            p.cgca_codigo,
            c.serie AS serie_nombre,
            p.modulo_siaf,
            p.rol,
            p.usuario_id,
            p.puede_ver_metadatos,
            p.puede_ver_stream,
            p.puede_descargar_original,
            p.puede_descargar_version_publica,
            p.puede_subir,
            p.puede_sellar,
            p.puede_versionar,
            p.aplica_marca_agua,
            p.estatus_registro,
            p.usuario_c,
            p.fecha_c
        FROM archivos.acl_permiso_carpeta p
        LEFT JOIN archivos.cgca_catalogo c ON p.cgca_codigo = c.cgca_codigo
        WHERE p.estatus_registro = COALESCE((p_filtros->>'estatus_registro')::smallint, 1)
          AND (v_cgca IS NULL OR p.cgca_codigo = v_cgca OR p.cgca_codigo = '*')
          AND (v_rol IS NULL OR p.rol = v_rol)
        ORDER BY p.cgca_codigo ASC, p.rol ASC
    ) r;

    RETURN jsonb_build_object('error', 0, 'mensaje', 'OK', 'data', v_resultado);
EXCEPTION WHEN OTHERS THEN
    RETURN jsonb_build_object('error', -2, 'mensaje', 'Error en fn_leer_permisos_carpeta: ' || SQLERRM, 'data', '[]'::jsonb);
END;
$$;
-- SP 2: archivos.fn_evaluar_acceso_documento (Evaluación en Caliente)
CREATE OR REPLACE FUNCTION archivos.fn_evaluar_acceso_documento(
    p_documento_id UUID,
    p_usuario VARCHAR(50),
    p_rol VARCHAR(50),
    p_accion VARCHAR(30) -- 'STREAM', 'DESCARGAR', 'SUBIR', 'SELLAR'
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = archivos, public
AS $$
DECLARE
    v_cgca VARCHAR(50);
    v_clasificacion VARCHAR(25);
    v_puede BOOLEAN := FALSE;
    v_marca_agua BOOLEAN := TRUE;
BEGIN
    -- 1. Obtener serie y clasificación del documento
    SELECT cgca_codigo, clasificacion_seguridad
    INTO v_cgca, v_clasificacion
    FROM archivos.documento
    WHERE id = p_documento_id AND estatus_registro = 1;

    IF v_cgca IS NULL THEN
        RETURN jsonb_build_object('autorizado', FALSE, 'motivo', 'Documento no encontrado o inactivo.');
    END IF;

    -- 2. El Administrador General de Archivos tiene permiso irrestricto
    IF p_rol = 'ADMIN_ARCHIVOS' OR p_rol = 'ADMIN_SISTEMA' THEN
        RETURN jsonb_build_object('autorizado', TRUE, 'marca_agua', FALSE);
    END IF;

    -- 3. Evaluar reglas ACL específicas o comodines
    IF p_accion = 'STREAM' THEN
        SELECT puede_ver_stream, aplica_marca_agua INTO v_puede, v_marca_agua
        FROM archivos.acl_permiso_carpeta
        WHERE estatus_registro = 1
          AND (cgca_codigo = v_cgca OR cgca_codigo = '*')
          AND (rol = p_rol OR usuario_id = (SELECT id_usuario FROM config.usuarios WHERE clave_usuario = p_usuario LIMIT 1))
        ORDER BY (CASE WHEN cgca_codigo = '*' THEN 1 ELSE 2 END) DESC LIMIT 1;

    ELSIF p_accion = 'DESCARGAR' THEN
        -- Si es información confidencial y el usuario no es el área productora, solo puede descargar versión pública
        SELECT puede_descargar_original INTO v_puede
        FROM archivos.acl_permiso_carpeta
        WHERE estatus_registro = 1
          AND (cgca_codigo = v_cgca OR cgca_codigo = '*')
          AND (rol = p_rol OR usuario_id = (SELECT id_usuario FROM config.usuarios WHERE clave_usuario = p_usuario LIMIT 1))
        ORDER BY (CASE WHEN cgca_codigo = '*' THEN 1 ELSE 2 END) DESC LIMIT 1;
        v_marca_agua := FALSE;
    END IF;

    -- Si no hay regla específica, denegar por defecto
    v_puede := COALESCE(v_puede, FALSE);

    RETURN jsonb_build_object(
        'autorizado', v_puede,
        'marca_agua', COALESCE(v_marca_agua, TRUE),
        'motivo', CASE WHEN NOT v_puede THEN 'No cuenta con facultades de ' || p_accion || ' para esta serie.' ELSE 'OK' END
    );
END;
$$;
4 Servicios API REST (Swagger / NestJS)
Método Endpoint Guards Descripción
GET /api/v1/archivos/acl JwtAuthGuard, Roles('ADMIN_ARCHIVOS') Consulta la matriz completa de permisos por carpeta y rol.
POST /api/v1/archivos/acl Roles('ADMIN_ARCHIVOS') Asigna privilegios de lectura, streaming, descarga o subida a un rol o usuario.
PATCH /api/v1/archivos/acl/:id Roles('ADMIN_ARCHIVOS') Modifica banderas de descarga o marca de agua.
GET /api/v1/archivos/:id/permisos-usuario JwtAuthGuard Retorna los permisos en caliente del usuario actual sobre el archivo indicado (para ocultar botones en el frontend).
