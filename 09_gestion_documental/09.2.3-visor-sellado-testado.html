09.2.3

Visor de Expedientes, Sellado Digital y Testado IVAI

Visor web interactivo (DocuWare Universal Viewer) equipado con paleta de sellos administrativos institucionales de auditoría y herramienta de redacción/testado de datos personales para la generación de Versiones Públicas conforme a la LGTAIP e IVAI.

Pendiente de desarrollo Herramienta Interactiva (DOC-08) LGTAIP / LGPDPPSO / IVAI Benchmark: DocuWare Stamps
🛡️ Sellos Digitales y Testado Seguro de Transparencia

Este componente fusiona dos necesidades críticas del Poder Judicial:

1. Sellado Digital (DocuWare Stamps): Los funcionarios autorizados pueden estampar sellos visuales (Revisión Conforme, Autorizado Pago, Pagado, Contabilizado) directamente en el visor. Cada sello asienta un evento criptográfico auditado en la bitácora inmutable (Art. 45 LGA).

2. Testado de Datos Personales (DocuWare Redaction): Permite cubrir datos sensibles (cuentas particulares, RFC de personas físicas, firmas autógrafas) mediante rectángulos negros para generar una Versión Pública aprobada por el Comité de Transparencia, manteniendo intacto el documento original en custodia interna.

1 Descripción General

El módulo 09.2.3 Visor de Expedientes, Sellado y Testado IVAI proporciona una interfaz enriquecida dentro del navegador sin requerir descargas locales ni lectores externos de PDF. Ofrece:

  • Streaming Seguro: Visualización en línea vía Content-Disposition: inline con tokens de sesión de corta duración.
  • Paleta de Sellos Institucionales: Estampado de sellos con usuario, cargo, fecha, hora y folio de trámite.
  • Herramienta de Testado Visual: Selector de áreas rectangulares para enmascarar información reservada o confidencial.
  • Exportación Dual: Descarga del expediente original (restringido a usuarios con permiso) o descarga de la versión pública testada (abierta a transparencia).
2 Procedimientos de Sellado y Versión Pública
-- Procedimiento para registrar un sello institucional
CREATE OR REPLACE FUNCTION archivos.fn_estampar_documento(
    p_documento_id UUID,
    p_tipo_sello VARCHAR(40),
    p_nota TEXT,
    p_usuario VARCHAR(50),
    p_ip VARCHAR(45)
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = archivos, public
AS $$
BEGIN
    -- 1. Insertar en bitácora inmutable
    INSERT INTO archivos.documento_bitacora (
        documento_id, evento, usuario, ip_cliente, detalles_json, fecha_evento
    ) VALUES (
        p_documento_id,
        'SELLO_' || UPPER(p_tipo_sello),
        p_usuario,
        p_ip,
        jsonb_build_object('tipo_sello', p_tipo_sello, 'nota', p_nota),
        clock_timestamp()
    );

    RETURN jsonb_build_object('error', 0, 'mensaje', 'Sello institucional aplicado con éxito.', 'data', null);
END;
$$;
