09.4.3

Cadena de Custodia y Bitácora Inmutable (LGA Art. 45)

Consola de auditoría forense y trazabilidad inmutable del subsistema de archivos. Registra cronológicamente cada evento de carga, visualización, descarga, estampado de sellos, versionamiento o baja lógica con usuario, IP, estampa de tiempo y contexto transaccional.

Pendiente de desarrollo Auditoría Forense (DOC-08) LGA Art. 45 Trazabilidad
🔒 Garantía de Inalterabilidad y No Repudio

El Artículo 45 de la Ley General de Archivos exige que los sistemas automatizados garanticen de manera fehaciente la Trazabilidad y la Cadena de Custodia de todo documento electrónico.

En el SIAF-PJEV, la tabla archivos.documento_bitacora opera como una bitácora inmutable en modo append-only (solo inserción, sin permisos de actualización ni borrado para ningún usuario operativo). Registra qué usuario consultó o descargó un documento, desde qué dirección IP y en qué milisegundo exacto.

1 Descripción General

El módulo 09.4.3 Cadena de Custodia y Bitácora LGA es la herramienta de fiscalización interna del sistema documental. Permite a los Auditores del Órgano Interno de Control y al personal de la Dirección de Tecnologías:

  • Auditoría por Documento: Conocer la historia completa y genealógica de un archivo desde que fue subido hasta su eventual transferencia o dictamen.
  • Monitoreo de Accesos a Información Confidencial: Rastrear quién visualizó o descargó documentos marcados como RESERVADO o CONFIDENCIAL conforme a las leyes de transparencia.
  • Detección de Anomalías: Identificar descargas masivas inusuales, intentos de acceso fuera de horario laboral o peticiones desde IPs desconocidas.
2 Consulta de Auditoría y Stored Procedures
-- Consulta avanzada de auditoría forense
CREATE OR REPLACE FUNCTION archivos.fn_consultar_bitacora(
    p_filtros JSONB DEFAULT '{}'::jsonb
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = archivos, public
AS $$
DECLARE
    v_doc_id UUID;
    v_usuario VARCHAR(50);
    v_evento VARCHAR(40);
    v_resultado JSONB;
BEGIN
    v_doc_id := (p_filtros->>'documento_id')::uuid;
    v_usuario := p_filtros->>'usuario';
    v_evento := p_filtros->>'evento';

    SELECT COALESCE(jsonb_agg(row_to_json(r)), '[]'::jsonb)
    INTO v_resultado
    FROM (
        SELECT 
            b.id,
            b.documento_id,
            d.nombre_original,
            d.hash_sha256,
            b.evento,
            b.usuario,
            b.ip_cliente,
            b.user_agent,
            b.detalles_json,
            b.fecha_evento
        FROM archivos.documento_bitacora b
        JOIN archivos.documento d ON b.documento_id = d.id
        WHERE (v_doc_id IS NULL OR b.documento_id = v_doc_id)
          AND (v_usuario IS NULL OR b.usuario = v_usuario)
          AND (v_evento IS NULL OR b.evento = v_evento)
        ORDER BY b.fecha_evento DESC
        LIMIT 100
    ) r;

    RETURN jsonb_build_object('error', 0, 'mensaje', 'OK', 'data', v_resultado);
END;
$$;
