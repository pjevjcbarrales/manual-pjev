09.3.2

Transferencias Documentales (Primaria y Secundaria)

Proceso formal y transaccional para la transferencia de expedientes digitales conforme al CADIDO: Transferencia Primaria (de Archivo de Trámite a Concentración) y Transferencia Secundaria (de Concentración a Archivo Histórico), con actas de entrega-recepción foliadas e inmutabilidad digital.

Pendiente de desarrollo Proceso Transaccional (DOC-08) LGA Arts. 30–32
📦 El Tránsito por las Edades del Documento

La Ley General de Archivos prohíbe mantener expedientes cerrados indefinidamente en las oficinas operativas.

Cuando concluye la vigencia activa estipulada en el CADIDO (ej. 1 año para pólizas o afectaciones concluidas), el sistema genera la Cédula de Transferencia Primaria y cambia el estado archivístico a CONCENTRACION, bloqueando cualquier modificación posterior y asegurando la custodia precautoria para auditorías del ORFIS o la ASF.

1 Descripción General

El módulo 09.3.2 Transferencias Documentales administra los dos grandes hitos de transición en la vida de los archivos:

  1. Transferencia Primaria:
    • Aplica a expedientes con vigencia de trámite cumplida.
    • La Unidad Productora (ej. Recursos Financieros) formula el paquete de transferencia.
    • El Archivo de Concentración revisa el inventario, coteja firmas y hashes SHA-256, y emite el acuse formal de recepción.
    • Los documentos pasan a modo Solo Lectura Inmutable (WORM).
  2. Transferencia Secundaria:
    • Aplica a expedientes que concluyen sus años en Concentración y cuyo CADIDO dictaminó destino TRANSFERENCIA_HISTORICA por poseer valores testimoniales o jurídicos permanentes.
    • Ingresan formalmente al Archivo Histórico del PJEV para preservación digital perpetua en formato PDF/A.
2 Servicios y Stored Procedures
-- Procedimiento para ejecutar la Transferencia Primaria masiva
CREATE OR REPLACE FUNCTION archivos.fn_transferencia_primaria(
    p_cgca_codigo VARCHAR(50),
    p_ejercicio INT,
    p_usuario VARCHAR(50),
    p_folio_acta VARCHAR(100)
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = archivos, public
AS $$
DECLARE
    v_total_transferidos INT;
BEGIN
    -- 1. Actualizar estado archivístico a CONCENTRACION
    WITH actualizados AS (
        UPDATE archivos.documento
        SET estado_archivistico = 'CONCENTRACION',
            fecha_cierre_tramite = CURRENT_DATE,
            usuario_m = p_usuario,
            fecha_m = clock_timestamp()
        WHERE cgca_codigo = p_cgca_codigo
          AND estado_archivistico = 'TRAMITE'
          AND estatus_registro = 1
          AND EXTRACT(YEAR FROM fecha_c) <= p_ejercicio
        RETURNING id
    )
    SELECT COUNT(*) INTO v_total_transferidos FROM actualizados;

    -- 2. Asentar en bitácora inmutable por cada documento
    INSERT INTO archivos.documento_bitacora (
        documento_id, evento, usuario, detalles_json
    )
    SELECT 
        d.id,
        'TRANSFERENCIA_PRIMARIA',
        p_usuario,
        jsonb_build_object('folio_acta', p_folio_acta, 'ejercicio', p_ejercicio, 'destino', 'ARCHIVO_CONCENTRACION')
    FROM archivos.documento d
    WHERE d.cgca_codigo = p_cgca_codigo 
      AND d.estado_archivistico = 'CONCENTRACION'
      AND d.fecha_cierre_tramite = CURRENT_DATE;

    RETURN jsonb_build_object(
        'error', 0,
        'mensaje', 'Transferencia primaria concluida exitosamente.',
        'data', jsonb_build_object('total_transferidos', v_total_transferidos, 'folio_acta', p_folio_acta)
    );
END;
$$;
