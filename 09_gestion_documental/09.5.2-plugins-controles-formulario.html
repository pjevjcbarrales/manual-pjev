09.5.2

Plugins y Controles UI para Formularios (Next.js / React)

Catálogo de componentes y controles de interfaz de usuario desacoplados, listos para ser importados en cualquier formulario del SIAF-PJEV (Cuentas por Pagar, Afectación de Gastos, Orden de Pago, Registro de Ingresos, Contratos y Pólizas) para adjuntar, visualizar, estampar sellos y estructurar recopiladores digitales con una sola línea de código.

Guía de Desarrollo Frontend React / Next.js / TypeScript Componentes Reutilizables Estándar UI PJEV
🧩 Plug & Play en Formularios del SIAF

El equipo de desarrollo (Cristian, Eunice, Daryl) no debe programar la lógica de subida de archivos, cálculo de SHA-256 ni conexión con storage en cada módulo.

Para incorporar el expediente digital completo en una pantalla de Afectación de Gastos o en una Póliza Contable, basta con importar el componente <EntityFiles /> indicando el módulo y el ID del registro. El componente se encarga de la tabla de archivos, la zona Drag & Drop, la previsualización modal, las insignias CADIDO y el estampado de sellos oficiales.

1 Catálogo de Controles Disponibles
Control / Componente Ubicación Propósito y Cuándo Usarlo
<EntityFiles /> src/components/files/EntityFiles.tsx Gestor Integral de Expediente: Tabla completa con dropzone, lista de documentos vinculados, preview en modal, descarga, sellado y borrado lógico. Se usa en la pestaña de anexos o pie de página de cualquier formulario maestro.
<SingleFileField /> src/components/files/SingleFileField.tsx Campo de Archivo Específico: Campo de formulario para requerir un único documento obligatorio (ej. "Subir Contrato Firmado (PDF)" o "Ficha de Depósito SEFIPLAN"). Muestra estado de carga, chip con nombre y botón de previsualización.
<ScanBatchDropzone /> src/components/files/ScanBatchDropzone.tsx Zona de Digitalización Masiva: Diseñado para Contabilidad y Archivo. Recibe PDFs multi-página escaneados, reconoce códigos QR u hojas separadoras y divide automáticamente las pólizas armando los Recopiladores Digitales.
<FilePreviewModal /> src/components/files/FilePreviewModal.tsx Visor Universal Web: Modal interactivo con zoom, rotación, visualización de PDF/A en canvas, presentación limpia de XML CFDI 4.0 mediante XSLT, e inspección de sellos y firmas.
<DigitalStampPicker /> src/components/files/DigitalStampPicker.tsx Paleta de Sellos Institucionales: Botón desplegable que muestra los sellos a los que el usuario tiene acceso (Revisión Conforme, Autorizado Pago, etc.) y los estampa directamente en el documento.
<ArchivalBadge /> src/components/files/ArchivalBadge.tsx Insignia Semafórica LGA: Muestra si el documento está en Trámite, Concentración o Histórico, y los años de vigencia restantes según el CADIDO.
2 Interfaces TypeScript y Props
// 1. Props para el componente maestro 
export interface EntityFilesProps {
  moduloSiaf: 'cxp' | 'contabilidad' | 'presupuesto' | 'ingresos' | 'materiales';
  entidadOrigen: string;              // ej: 'afectacion_gasto', 'poliza', 'orden_pago'
  registroId: string | number;        // ID del registro guardado (o ticket temporal si es nuevo)
  isTemporal?: boolean;               // TRUE si el formulario aún no se guarda en firme
  readOnly?: boolean;                 // TRUE para deshabilitar subidas o eliminaciones
  permitirSellos?: boolean;           // TRUE para mostrar la paleta de sellos digitales
  cgcaCodigoSugerido?: string;        // ej: 'PJEV-DGA-RF-1S.02'
  onFilesChanged?: (count: number) => void;
}

// 2. Props para el campo individual 
export interface SingleFileFieldProps {
  label: string;
  tipoDocumento: string;              // ej: 'CFDI_PDF_REP', 'CON_OBR_PUB'
  value?: string;                     // UUID del archivo actualmente asignado
  onChange: (fileId: string | null) => void;
  required?: boolean;
  disabled?: boolean;
  accept?: string;                    // ej: '.pdf, .xml'
  maxSizeMB?: number;
}
3 Ejemplos Prácticos de Integración en Formularios

Ejemplo 1: Integración de Expediente en Formulario de Afectación de Gastos (CXP)

// src/modules/cxp/components/AfectacionGastoForm.tsx
import React, { useState } from 'react';
import { EntityFiles } from '@/components/files/EntityFiles';

export const AfectacionGastoForm = ({ idAfectacion, esNuevo }: Props) => {
  // Ticket temporal generado en el cliente si es nuevo registro
  const [ticketTemp] = useState(() => esNuevo ? crypto.randomUUID() : null);

  return (
    <form className="siaf-form">
      <h3>Datos Generales del Gasto</h3>
      {/* Campos del encabezado: Proveedor, Monto, COG, Centro Gestor */}

      <div className="anexos-section" style={{ marginTop: '24px' }}>
        <h4>Expediente Digital y Comprobantes</h4>
        
        {/* COMPONENTE REUTILIZABLE: Todo el manejo de archivos en 1 línea */}
        <EntityFiles
          moduloSiaf="cxp"
          entidadOrigen="afectacion_gasto"
          registroId={esNuevo ? ticketTemp! : idAfectacion}
          isTemporal={esNuevo}
          cgcaCodigoSugerido="PJEV-DGA-RF-1S.02"
          permitirSellos={!esNuevo}
        />
      </div>

      <button type="submit">Guardar Afectación</button>
    </form>
  );
};
