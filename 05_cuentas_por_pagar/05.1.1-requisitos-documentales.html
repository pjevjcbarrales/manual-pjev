05.1.1

Requisitos documentales

Catálogo de soportes y matriz de exigibilidad para la revisión de expedientes de gasto.

Etapa 2 · Tesorería / Cuentas por Pagar

1 Descripción general

Tesorería configura qué documentos se requieren en cada procedimiento de gasto. El área usuaria integra el expediente en el trámite y consulta qué requisitos están cubiertos, pendientes o vencidos antes de enviarlo a revisión.

El módulo administra tipos de soporte y su exigibilidad. La Afectación del Gasto consulta los adjuntos y verifica el expediente al enviarlo a revisión. La recepción institucional, las autorizaciones y el pago siguen sus flujos respectivos.

4 Modelo de datos

El estándar de nomenclatura PostgreSQL del SIAF usa el prefijo de la entidad al inicio de los campos de negocio. El catálogo usa doc_ y la matriz usa rps_. Las referencias de CxP conservan f_. estatus_registro y los campos de auditoría tienen nombres comunes.

Las tablas muestran los nombres finales del diseño. La migración de los ocho campos renombrados sigue pendiente en PostgreSQL.

La matriz impone unicidad en (f_procedimiento_codigo, f_doc_id) e indexa por procedimiento y por documento junto con el estatus. El código de procedimiento se resuelve en contabilidad.matriz_grupos_procedimiento, incluidos los alias heredados admitidos por la función.

El renombre físico requiere actualizar las referencias SQL de las funciones LEER, ABC y de validación del checklist. Las claves JSON de esas funciones y de la API se conservan mediante el mapeo al nombre físico.

5 Funciones PostgreSQL y triggers

Las firmas y las definiciones SQL de esta sección corresponden al contrato instalado, anterior a la migración de nombres del modelo de datos. El estándar reserva fn_abc_* para funciones nuevas de alta, baja y cambio cuando corresponda. Esta implementación conserva su nombre y numeración fn_crud_*. Las restricciones físicas y estas funciones gobiernan las escrituras. La migración del módulo carece de triggers propios.

CREATE OR REPLACE FUNCTION cxp.fn_leer_requisitos_documentales(
    p_usuario VARCHAR DEFAULT 'SISTEMA',
    p_ejercicio INTEGER DEFAULT NULL,
    p_buscar VARCHAR DEFAULT NULL,
    p_doc_id BIGINT DEFAULT NULL,
    p_procedimiento_codigo VARCHAR DEFAULT NULL,
    p_estatus SMALLINT DEFAULT 1
)
RETURNS JSONB
LANGUAGE plpgsql
STABLE
SECURITY DEFINER
SET search_path = cxp, contabilidad, config, pg_catalog
AS $function$
DECLARE
    v_data JSONB;
    v_proc_filtro VARCHAR(40) := NULLIF(UPPER(BTRIM(COALESCE(p_procedimiento_codigo, ''))), '');
    v_buscar_limpio VARCHAR(100) := NULLIF(BTRIM(COALESCE(p_buscar, '')), '');
BEGIN
    SELECT jsonb_agg(
        jsonb_build_object(
            'doc_id', d.doc_id,
            'doc_codigo', d.doc_codigo,
            'doc_nombre', d.doc_nombre,
            'emisor_origen', d.emisor_origen,
            'doc_descripcion', d.doc_descripcion,
            'formato_permitido', d.formato_permitido,
            'tamano_max_mb', d.tamano_max_mb,
            'valida_sat', d.valida_sat,
            'valida_vigencia_dias', d.valida_vigencia_dias,
            'estatus_registro', d.estatus_registro,
            'usuario_c', d.usuario_c,
            'fecha_c', d.fecha_c,
            'usuario_m', d.usuario_m,
            'fecha_m', d.fecha_m,
            'requisitos_asociados', COALESCE((
                SELECT jsonb_agg(
                    jsonb_build_object(
                        'rps_id', r.rps_id,
                        'procedimiento_id', p.matriz_grupo_procedimiento_id,
                        'procedimiento_codigo', r.f_procedimiento_codigo,
                        'procedimiento_codigo_legado', p.mgp_codigo_legado,
                        'procedimiento_nombre', COALESCE(p.mgp_nombre, r.f_procedimiento_codigo),
                        'grupo_id', g.matriz_grupo_id,
                        'grupo_codigo', g.mgt_codigo,
                        'grupo_titulo', g.mgt_titulo,
                        'tipo_beneficiario', p.mgp_tipo_beneficiario,
                        'nivel_exigencia', r.nivel_exigencia,
                        'condicion_sql', r.condicion_sql,
                        'orden_visual', r.orden_visual,
                        'estatus_registro', r.estatus_registro
                    ) ORDER BY COALESCE(g.mgt_numero, 99), COALESCE(p.matriz_grupo_procedimiento_id, 999), r.orden_visual
                )
                FROM cxp.requisitos_procedimiento_soporte r
                LEFT JOIN contabilidad.matriz_grupos_procedimiento p
                  ON p.mgp_codigo = r.f_procedimiento_codigo
                 AND p.estatus_registro = 1
                LEFT JOIN contabilidad.matriz_grupos_tramite g
                  ON g.matriz_grupo_id = p.matriz_grupo_id
                 AND g.mgt_ambito = 'E'
                WHERE r.f_doc_id = d.doc_id
                  AND r.estatus_registro = 1
                  AND (
                    v_proc_filtro IS NULL
                    OR r.f_procedimiento_codigo = v_proc_filtro
                    OR p.mgp_codigo_legado = v_proc_filtro
                  )
            ), '[]'::jsonb)
        ) ORDER BY d.doc_id, d.doc_codigo
    ) INTO v_data
    FROM cxp.catalogo_documentos_soporte d
    WHERE (p_estatus IS NULL OR d.estatus_registro = p_estatus)
      AND (p_doc_id IS NULL OR d.doc_id = p_doc_id)
      AND (
        v_buscar_limpio IS NULL
        OR d.doc_codigo ILIKE '%' || v_buscar_limpio || '%'
        OR d.doc_nombre ILIKE '%' || v_buscar_limpio || '%'
        OR COALESCE(d.emisor_origen, '') ILIKE '%' || v_buscar_limpio || '%'
        OR COALESCE(d.doc_descripcion, '') ILIKE '%' || v_buscar_limpio || '%'
      )
      AND (
        v_proc_filtro IS NULL
        OR EXISTS (
          SELECT 1
            FROM cxp.requisitos_procedimiento_soporte r2
            LEFT JOIN contabilidad.matriz_grupos_procedimiento p2
              ON p2.mgp_codigo = r2.f_procedimiento_codigo
             AND p2.estatus_registro = 1
           WHERE r2.f_doc_id = d.doc_id
             AND r2.estatus_registro = 1
             AND (
               r2.f_procedimiento_codigo = v_proc_filtro
               OR p2.mgp_codigo_legado = v_proc_filtro
             )
        )
      );

    RETURN jsonb_build_object(
        'cod_resultado', 0,
        'msg_resultado', 'OK',
        'error', 0,
        'mensaje', 'OK',
        'data', COALESCE(v_data, '[]'::jsonb)
    );
EXCEPTION WHEN OTHERS THEN
    RETURN jsonb_build_object(
        'cod_resultado', -2,
        'msg_resultado', SQLERRM,
        'error', -2,
        'mensaje', SQLERRM,
        'data', NULL
    );
END;
$function$;

CREATE OR REPLACE FUNCTION cxp.fn_crud_requisitos_documentales(
    p_accion SMALLINT,
    p_usuario VARCHAR,
    p_ejercicio INTEGER,
    p_doc_id BIGINT,
    p_datos JSONB
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = cxp, contabilidad, config, pg_catalog
AS $function$
DECLARE
    v_id BIGINT;
    v_item JSONB;
    v_usuario VARCHAR(50) := COALESCE(NULLIF(BTRIM(p_usuario), ''), 'SISTEMA');
    v_codigo VARCHAR(20);
    v_nombre VARCHAR(150);
    v_proc_input VARCHAR(40);
    v_proc_canonico VARCHAR(40);
    v_nivel VARCHAR(20);
    v_codigos_enviados VARCHAR(40)[] := ARRAY[]::VARCHAR(40)[];
BEGIN
    -- 1 = ALTA
    IF p_accion = 1 THEN
        v_codigo := UPPER(BTRIM(COALESCE(p_datos->>'doc_codigo', '')));
        v_nombre := BTRIM(COALESCE(p_datos->>'doc_nombre', ''));

        IF v_codigo = '' OR v_nombre = '' THEN
            RETURN jsonb_build_object(
                'cod_resultado', -1,
                'msg_resultado', 'El código y el nombre del documento son obligatorios.',
                'error', -1,
                'mensaje', 'El código y el nombre del documento son obligatorios.',
                'data', NULL
            );
        END IF;

        IF EXISTS (SELECT 1 FROM cxp.catalogo_documentos_soporte WHERE doc_codigo = v_codigo) THEN
            RETURN jsonb_build_object(
                'cod_resultado', -1,
                'msg_resultado', 'El código de documento ya se encuentra registrado.',
                'error', -1,
                'mensaje', 'El código de documento ya se encuentra registrado.',
                'data', NULL
            );
        END IF;

        INSERT INTO cxp.catalogo_documentos_soporte (
            doc_codigo,
            doc_nombre,
            emisor_origen,
            doc_descripcion,
            formato_permitido,
            tamano_max_mb,
            valida_sat,
            valida_vigencia_dias,
            estatus_registro,
            usuario_c,
            fecha_c
        ) VALUES (
            v_codigo,
            v_nombre,
            NULLIF(BTRIM(COALESCE(p_datos->>'emisor_origen', '')), ''),
            NULLIF(BTRIM(COALESCE(p_datos->>'doc_descripcion', '')), ''),
            UPPER(BTRIM(COALESCE(NULLIF(p_datos->>'formato_permitido', ''), 'PDF'))),
            GREATEST(COALESCE((p_datos->>'tamano_max_mb')::NUMERIC, 10.0), 0.1),
            COALESCE((p_datos->>'valida_sat')::BOOLEAN, false),
            NULLIF(BTRIM(COALESCE(p_datos->>'valida_vigencia_dias', '')), '')::INTEGER,
            1,
            v_usuario,
            clock_timestamp()
        ) RETURNING doc_id INTO v_id;

        IF p_datos ? 'procedimientos' AND jsonb_typeof(p_datos->'procedimientos') = 'array' THEN
            FOR v_item IN SELECT * FROM jsonb_array_elements(p_datos->'procedimientos') LOOP
                v_proc_input := UPPER(BTRIM(COALESCE(v_item->>'procedimiento_codigo', '')));
                v_nivel := UPPER(BTRIM(COALESCE(v_item->>'nivel_exigencia', 'OBLIGATORIO')));

                IF v_proc_input <> '' AND v_nivel IN ('OBLIGATORIO', 'CONDICIONAL', 'OPCIONAL') THEN
                    FOR v_proc_canonico IN
                        SELECT p.mgp_codigo
                          FROM contabilidad.matriz_grupos_procedimiento p
                         WHERE p.estatus_registro = 1
                           AND (p.mgp_codigo = v_proc_input OR p.mgp_codigo_legado = v_proc_input)
                        UNION
                        SELECT v_proc_input
                         WHERE NOT EXISTS (
                           SELECT 1
                             FROM contabilidad.matriz_grupos_procedimiento p
                            WHERE p.estatus_registro = 1
                              AND (p.mgp_codigo = v_proc_input OR p.mgp_codigo_legado = v_proc_input)
                         )
                    LOOP
                        INSERT INTO cxp.requisitos_procedimiento_soporte (
                            f_procedimiento_codigo,
                            f_doc_id,
                            nivel_exigencia,
                            condicion_sql,
                            orden_visual,
                            estatus_registro,
                            usuario_c,
                            fecha_c
                        ) VALUES (
                            v_proc_canonico,
                            v_id,
                            v_nivel,
                            NULLIF(BTRIM(COALESCE(v_item->>'condicion_sql', '')), ''),
                            GREATEST(COALESCE((v_item->>'orden_visual')::SMALLINT, 1), 1),
                            1,
                            v_usuario,
                            clock_timestamp()
                        ) ON CONFLICT (f_procedimiento_codigo, f_doc_id) DO UPDATE
                        SET nivel_exigencia = EXCLUDED.nivel_exigencia,
                            condicion_sql = EXCLUDED.condicion_sql,
                            orden_visual = EXCLUDED.orden_visual,
                            estatus_registro = 1,
                            usuario_m = v_usuario,
                            fecha_m = clock_timestamp();
                    END LOOP;
                END IF;
            END LOOP;
        END IF;

        RETURN jsonb_build_object(
            'cod_resultado', 0,
            'msg_resultado', 'Documento soporte registrado con éxito.',
            'error', 0,
            'mensaje', 'Documento soporte registrado con éxito.',
            'data', jsonb_build_object('doc_id', v_id, 'doc_codigo', v_codigo)
        );

    -- 2 = MODIFICACIÓN
    ELSIF p_accion = 2 THEN
        IF p_doc_id IS NULL OR NOT EXISTS (SELECT 1 FROM cxp.catalogo_documentos_soporte WHERE doc_id = p_doc_id) THEN
            RETURN jsonb_build_object(
                'cod_resultado', -1,
                'msg_resultado', 'El documento soporte especificado no existe.',
                'error', -1,
                'mensaje', 'El documento soporte especificado no existe.',
                'data', NULL
            );
        END IF;

        UPDATE cxp.catalogo_documentos_soporte SET
            doc_nombre = COALESCE(NULLIF(BTRIM(p_datos->>'doc_nombre'), ''), doc_nombre),
            emisor_origen = CASE
                WHEN p_datos ? 'emisor_origen' THEN NULLIF(BTRIM(p_datos->>'emisor_origen'), '')
                ELSE emisor_origen
            END,
            doc_descripcion = CASE
                WHEN p_datos ? 'doc_descripcion' THEN NULLIF(BTRIM(p_datos->>'doc_descripcion'), '')
                ELSE doc_descripcion
            END,
            formato_permitido = COALESCE(NULLIF(UPPER(BTRIM(p_datos->>'formato_permitido')), ''), formato_permitido),
            tamano_max_mb = COALESCE(NULLIF(BTRIM(p_datos->>'tamano_max_mb'), '')::NUMERIC, tamano_max_mb),
            valida_sat = COALESCE((p_datos->>'valida_sat')::BOOLEAN, valida_sat),
            valida_vigencia_dias = CASE
                WHEN p_datos ? 'valida_vigencia_dias' THEN NULLIF(BTRIM(COALESCE(p_datos->>'valida_vigencia_dias', '')), '')::INTEGER
                ELSE valida_vigencia_dias
            END,
            usuario_m = v_usuario,
            fecha_m = clock_timestamp()
        WHERE doc_id = p_doc_id;

        IF p_datos ? 'procedimientos' AND jsonb_typeof(p_datos->'procedimientos') = 'array' THEN
            FOR v_item IN SELECT * FROM jsonb_array_elements(p_datos->'procedimientos') LOOP
                v_proc_input := UPPER(BTRIM(COALESCE(v_item->>'procedimiento_codigo', '')));
                v_nivel := UPPER(BTRIM(COALESCE(v_item->>'nivel_exigencia', '')));

                IF v_proc_input <> '' THEN
                    FOR v_proc_canonico IN
                        SELECT p.mgp_codigo
                          FROM contabilidad.matriz_grupos_procedimiento p
                         WHERE p.estatus_registro = 1
                           AND (p.mgp_codigo = v_proc_input OR p.mgp_codigo_legado = v_proc_input)
                        UNION
                        SELECT v_proc_input
                         WHERE NOT EXISTS (
                           SELECT 1
                             FROM contabilidad.matriz_grupos_procedimiento p
                            WHERE p.estatus_registro = 1
                              AND (p.mgp_codigo = v_proc_input OR p.mgp_codigo_legado = v_proc_input)
                         )
                    LOOP
                        IF v_nivel IN ('OBLIGATORIO', 'CONDICIONAL', 'OPCIONAL') THEN
                            v_codigos_enviados := array_append(v_codigos_enviados, v_proc_canonico);

                            INSERT INTO cxp.requisitos_procedimiento_soporte (
                                f_procedimiento_codigo,
                                f_doc_id,
                                nivel_exigencia,
                                condicion_sql,
                                orden_visual,
                                estatus_registro,
                                usuario_c,
                                fecha_c
                            ) VALUES (
                                v_proc_canonico,
                                p_doc_id,
                                v_nivel,
                                NULLIF(BTRIM(COALESCE(v_item->>'condicion_sql', '')), ''),
                                GREATEST(COALESCE((v_item->>'orden_visual')::SMALLINT, 1), 1),
                                1,
                                v_usuario,
                                clock_timestamp()
                            ) ON CONFLICT (f_procedimiento_codigo, f_doc_id) DO UPDATE
                            SET nivel_exigencia = EXCLUDED.nivel_exigencia,
                                condicion_sql = EXCLUDED.condicion_sql,
                                orden_visual = EXCLUDED.orden_visual,
                                estatus_registro = 1,
                                usuario_m = v_usuario,
                                fecha_m = clock_timestamp();
                        ELSE
                            UPDATE cxp.requisitos_procedimiento_soporte
                               SET estatus_registro = 0,
                                   usuario_m = v_usuario,
                                   fecha_m = clock_timestamp()
                             WHERE f_doc_id = p_doc_id
                               AND f_procedimiento_codigo = v_proc_canonico;
                        END IF;
                    END LOOP;
                END IF;
            END LOOP;

            IF COALESCE((p_datos->>'reemplazar_matriz')::BOOLEAN, false) THEN
                UPDATE cxp.requisitos_procedimiento_soporte
                   SET estatus_registro = 0,
                       usuario_m = v_usuario,
                       fecha_m = clock_timestamp()
                 WHERE f_doc_id = p_doc_id
                   AND NOT (f_procedimiento_codigo = ANY(v_codigos_enviados));
            END IF;
        END IF;

        RETURN jsonb_build_object(
            'cod_resultado', 0,
            'msg_resultado', 'Documento soporte actualizado correctamente.',
            'error', 0,
            'mensaje', 'Documento soporte actualizado correctamente.',
            'data', jsonb_build_object('doc_id', p_doc_id)
        );

    -- 3 = BAJA LÓGICA
    ELSIF p_accion = 3 THEN
        UPDATE cxp.catalogo_documentos_soporte
           SET estatus_registro = 0,
               usuario_m = v_usuario,
               fecha_m = clock_timestamp()
         WHERE doc_id = p_doc_id;

        RETURN jsonb_build_object(
            'cod_resultado', 0,
            'msg_resultado', 'Documento soporte inactivado lógicamente.',
            'error', 0,
            'mensaje', 'Documento soporte inactivado lógicamente.',
            'data', jsonb_build_object('doc_id', p_doc_id, 'estatus_registro', 0)
        );

    -- 4 = REACTIVAR
    ELSIF p_accion = 4 THEN
        UPDATE cxp.catalogo_documentos_soporte
           SET estatus_registro = 1,
               usuario_m = v_usuario,
               fecha_m = clock_timestamp()
         WHERE doc_id = p_doc_id;

        RETURN jsonb_build_object(
            'cod_resultado', 0,
            'msg_resultado', 'Documento soporte reactivado con éxito.',
            'error', 0,
            'mensaje', 'Documento soporte reactivado con éxito.',
            'data', jsonb_build_object('doc_id', p_doc_id, 'estatus_registro', 1)
        );
    ELSE
        RETURN jsonb_build_object(
            'cod_resultado', -1,
            'msg_resultado', 'Acción ABC no admitida.',
            'error', -1,
            'mensaje', 'Acción ABC no admitida.',
            'data', NULL
        );
    END IF;
EXCEPTION WHEN OTHERS THEN
    RETURN jsonb_build_object(
        'cod_resultado', -2,
        'msg_resultado', SQLERRM,
        'error', -2,
        'mensaje', SQLERRM,
        'data', NULL
    );
END;

CREATE OR REPLACE FUNCTION cxp.fn_validar_checklist_afectacion(
    p_ag_id UUID,
    p_ejercicio_fiscal INTEGER DEFAULT NULL
)
RETURNS JSONB
LANGUAGE plpgsql
STABLE
SECURITY DEFINER
SET search_path = cxp, contabilidad, config, pg_catalog
AS $function$
DECLARE
    v_ag RECORD;
    v_proc_canonico VARCHAR(40);
    v_proc_nombre VARCHAR(150);
    v_tiene_cap_5000 BOOLEAN := false;
    v_items JSONB := '[]'::jsonb;
    v_faltantes JSONB := '[]'::jsonb;
    v_alertas JSONB := '[]'::jsonb;
    v_total_obligatorios INTEGER := 0;
    v_cumplidos_obligatorios INTEGER := 0;
    v_regla RECORD;
    v_doc_adjunto RECORD;
    v_nivel_efectivo VARCHAR(20);
    v_motivo_condicion TEXT;
    v_cumplido BOOLEAN;
    v_vigencia_vencida BOOLEAN;
    v_dias_antiguedad INTEGER;
    v_fecha_emision_doc DATE;
BEGIN
    SELECT a.ag_id,
           a.ejercicio_fiscal,
           a.folio,
           UPPER(BTRIM(COALESCE(a.f_procedimiento_codigo, ''))) AS f_procedimiento_codigo,
           COALESCE(a.importe_total_pago, 0) AS importe_total_pago,
           COALESCE(a.fecha_elaboracion, CURRENT_DATE) AS fecha_elaboracion,
           COALESCE(a.afecta_presupuesto, true) AS afecta_presupuesto,
           a.matriz_grupo_id
      INTO v_ag
      FROM cxp.afectaciones_gasto a
     WHERE a.ag_id = p_ag_id
       AND (p_ejercicio_fiscal IS NULL OR a.ejercicio_fiscal = p_ejercicio_fiscal)
       AND a.estatus_registro = 1
     ORDER BY a.ejercicio_fiscal DESC
     LIMIT 1;

    IF NOT FOUND THEN
        RETURN jsonb_build_object(
            'cod_resultado', -1,
            'msg_resultado', 'Afectación de gasto no localizada.',
            'error', -1,
            'valido', false,
            'mensaje', 'Afectación de gasto no localizada.',
            'data', NULL
        );
    END IF;

    SELECT p.mgp_codigo, p.mgp_nombre
      INTO v_proc_canonico, v_proc_nombre
      FROM contabilidad.matriz_grupos_procedimiento p
     WHERE p.estatus_registro = 1
       AND (p.mgp_codigo = v_ag.f_procedimiento_codigo OR p.mgp_codigo_legado = v_ag.f_procedimiento_codigo)
     ORDER BY CASE WHEN p.mgp_codigo = v_ag.f_procedimiento_codigo THEN 0 ELSE 1 END,
              p.matriz_grupo_procedimiento_id
     LIMIT 1;

    v_proc_canonico := COALESCE(v_proc_canonico, v_ag.f_procedimiento_codigo);
    v_proc_nombre := COALESCE(v_proc_nombre, v_ag.f_procedimiento_codigo);

    SELECT EXISTS (
        SELECT 1
          FROM cxp.afectaciones_gasto_detalles d
          JOIN config.catalogo_cog c ON c.cog_id = d.f_cog_id
         WHERE d.f_ag_id = v_ag.ag_id
           AND d.ejercicio_fiscal = v_ag.ejercicio_fiscal
           AND d.estatus_registro = 1
           AND LEFT(BTRIM(COALESCE(c.cog_cuentacompleta, '')), 1) = '5'
    ) INTO v_tiene_cap_5000;

    FOR v_regla IN
        SELECT r.rps_id,
               r.f_procedimiento_codigo,
               r.nivel_exigencia,
               r.condicion_sql,
               r.orden_visual,
               d.doc_id,
               d.doc_codigo,
               d.doc_nombre,
               d.emisor_origen,
               d.doc_descripcion,
               d.formato_permitido,
               d.tamano_max_mb,
               d.valida_sat,
               d.valida_vigencia_dias
          FROM cxp.requisitos_procedimiento_soporte r
          JOIN cxp.catalogo_documentos_soporte d
            ON d.doc_id = r.f_doc_id
           AND d.estatus_registro = 1
         WHERE r.estatus_registro = 1
           AND r.f_procedimiento_codigo = v_proc_canonico
         ORDER BY r.orden_visual, d.doc_id
    LOOP
        v_nivel_efectivo := v_regla.nivel_exigencia;
        v_motivo_condicion := NULL;

        -- RN-REQ-05: Condicionamiento por umbral económico ($300,000 MXN) o Capítulo 5000
        IF v_regla.nivel_exigencia = 'CONDICIONAL' THEN
            IF COALESCE(v_regla.condicion_sql, '') ILIKE '%300000%' AND v_ag.importe_total_pago > 300000 THEN
                v_nivel_efectivo := 'OBLIGATORIO';
                v_motivo_condicion := 'Obligatorio por superar el umbral de $300,000.00 MXN (RN-REQ-05).';
            ELSIF COALESCE(v_regla.condicion_sql, '') ILIKE '%5000%' AND v_tiene_cap_5000 THEN
                v_nivel_efectivo := 'OBLIGATORIO';
                v_motivo_condicion := 'Obligatorio por afectar partidas de Capítulo 5000 (Activo Fijo).';
            END IF;
        END IF;

        -- Buscar documento adjunto en config.documentos_soporte o cxp.afectaciones_gasto_cfdi
        v_doc_adjunto := NULL;
        SELECT ds.doc_id::text AS doc_id,
               ds.nombre_original,
               ds.mimetype,
               ds.tamanio_bytes,
               ds.cfdi_uuid,
               ds.cfdi_rfc_emisor,
               ds.cfdi_total,
               ds.observaciones,
               ds.fecha_c
          INTO v_doc_adjunto
          FROM config.documentos_soporte ds
         WHERE ds.estatus_registro = 1
           AND ds.referencia_uuid = v_ag.ag_id
           AND (
             UPPER(BTRIM(ds.tipo_documento)) = v_regla.doc_codigo
             OR (v_regla.doc_codigo = 'DOC-CFD-XML' AND (UPPER(BTRIM(ds.tipo_documento)) IN ('DOC-CFD-XML', 'CFDI_XML') OR ds.cfdi_uuid IS NOT NULL))
             OR (v_regla.doc_codigo = 'DOC-VAL-SAT' AND (UPPER(BTRIM(ds.tipo_documento)) = 'DOC-VAL-SAT' OR ds.cfdi_uuid IS NOT NULL))
             OR (v_regla.doc_codigo = 'DOC-CFD-PDF' AND UPPER(BTRIM(ds.tipo_documento)) IN ('DOC-CFD-PDF', 'CFDI_PDF'))
             OR (v_regla.doc_codigo = 'DOC-SOL-PAG' AND UPPER(BTRIM(ds.tipo_documento)) IN ('DOC-SOL-PAG', 'OFICIO_AUTORIZACION', 'SUF_PRES'))
             OR (v_regla.doc_codigo = 'DOC-CON-TRA' AND UPPER(BTRIM(ds.tipo_documento)) IN ('DOC-CON-TRA', 'CONTRATO'))
           )
         ORDER BY ds.fecha_c DESC, ds.doc_id DESC
         LIMIT 1;

        IF v_doc_adjunto.doc_id IS NULL AND v_regla.doc_codigo IN ('DOC-CFD-XML', 'DOC-VAL-SAT') THEN
            SELECT c.agc_id::text AS doc_id,
                   ('CFDI-' || c.uuid_cfdi::text || '.xml')::varchar AS nombre_original,
                   'application/xml'::varchar AS mimetype,
                   0::bigint AS tamanio_bytes,
                   c.uuid_cfdi::varchar AS cfdi_uuid,
                   NULL::varchar AS cfdi_rfc_emisor,
                   c.importe_total AS cfdi_total,
                   'SAT: VIGENTE'::text AS observaciones,
                   c.fecha_c
              INTO v_doc_adjunto
              FROM cxp.afectaciones_gasto_cfdi c
             WHERE c.f_ag_id = v_ag.ag_id
               AND c.ejercicio_fiscal = v_ag.ejercicio_fiscal
               AND c.estatus_registro = 1
             ORDER BY c.fecha_c DESC
             LIMIT 1;
        END IF;

        v_cumplido := (v_doc_adjunto.doc_id IS NOT NULL);
        v_vigencia_vencida := false;
        v_dias_antiguedad := NULL;

        -- RN-REQ-04: Control de vigencia (30 días naturales en Opiniones 32-D / SEFIPLAN)
        IF v_cumplido AND v_regla.valida_vigencia_dias IS NOT NULL THEN
            v_fecha_emision_doc := NULL;
            IF COALESCE(v_doc_adjunto.observaciones, '') ~ '[0-9]{4}-[0-9]{2}-[0-9]{2}' THEN
                BEGIN
                    v_fecha_emision_doc := (substring(v_doc_adjunto.observaciones from '[0-9]{4}-[0-9]{2}-[0-9]{2}'))::date;
                EXCEPTION WHEN OTHERS THEN
                    v_fecha_emision_doc := NULL;
                END;
            END IF;
            v_fecha_emision_doc := COALESCE(v_fecha_emision_doc, v_doc_adjunto.fecha_c::date);
            v_dias_antiguedad := (v_ag.fecha_elaboracion - v_fecha_emision_doc);

            IF v_dias_antiguedad > v_regla.valida_vigencia_dias THEN
                v_vigencia_vencida := true;
                v_cumplido := false;
            END IF;
        END IF;

        IF v_nivel_efectivo = 'OBLIGATORIO' THEN
            v_total_obligatorios := v_total_obligatorios + 1;
            IF v_cumplido THEN
                v_cumplidos_obligatorios := v_cumplidos_obligatorios + 1;
            ELSE
                v_faltantes := v_faltantes || jsonb_build_array(
                    jsonb_build_object(
                        'doc_id', v_regla.doc_id,
                        'doc_codigo', v_regla.doc_codigo,
                        'doc_nombre', v_regla.doc_nombre,
                        'nivel', v_nivel_efectivo,
                        'vigencia_vencida', v_vigencia_vencida,
                        'dias_antiguedad', v_dias_antiguedad,
                        'motivo', CASE
                            WHEN v_vigencia_vencida THEN format('Vigencia caduca (%s días > %s días permitidos por RN-REQ-04).', v_dias_antiguedad, v_regla.valida_vigencia_dias)
                            WHEN v_motivo_condicion IS NOT NULL THEN v_motivo_condicion
                            ELSE 'Documento obligatorio pendiente de adjuntar.'
                        END
                    )
                );
            END IF;
        ELSIF v_nivel_efectivo = 'CONDICIONAL' AND NOT v_cumplido THEN
            v_alertas := v_alertas || jsonb_build_array(
                jsonb_build_object(
                    'doc_codigo', v_regla.doc_codigo,
                    'doc_nombre', v_regla.doc_nombre,
                    'condicion_sql', v_regla.condicion_sql
                )
            );
        END IF;

        v_items := v_items || jsonb_build_array(
            jsonb_build_object(
                'rps_id', v_regla.rps_id,
                'doc_id', v_regla.doc_id,
                'doc_codigo', v_regla.doc_codigo,
                'doc_nombre', v_regla.doc_nombre,
                'emisor_origen', v_regla.emisor_origen,
                'formato_permitido', v_regla.formato_permitido,
                'tamano_max_mb', v_regla.tamano_max_mb,
                'valida_sat', v_regla.valida_sat,
                'valida_vigencia_dias', v_regla.valida_vigencia_dias,
                'nivel_configurado', v_regla.nivel_exigencia,
                'nivel_exigencia', v_nivel_efectivo,
                'condicion_sql', v_regla.condicion_sql,
                'motivo_condicion', v_motivo_condicion,
                'orden_visual', v_regla.orden_visual,
                'cumplido', v_cumplido,
                'vigencia_vencida', v_vigencia_vencida,
                'dias_antiguedad', v_dias_antiguedad,
                'archivo_adjunto', CASE
                    WHEN v_doc_adjunto.doc_id IS NOT NULL THEN jsonb_build_object(
                        'doc_soporte_id', v_doc_adjunto.doc_id,
                        'nombre_original', v_doc_adjunto.nombre_original,
                        'mimetype', v_doc_adjunto.mimetype,
                        'tamanio_bytes', v_doc_adjunto.tamanio_bytes,
                        'cfdi_uuid', v_doc_adjunto.cfdi_uuid,
                        'cfdi_rfc_emisor', v_doc_adjunto.cfdi_rfc_emisor,
                        'cfdi_total', v_doc_adjunto.cfdi_total,
                        'fecha_carga', v_doc_adjunto.fecha_c
                    )
                    ELSE NULL
                END
            )
        );
    END LOOP;

    IF jsonb_array_length(v_faltantes) > 0 THEN
        RETURN jsonb_build_object(
            'cod_resultado', -1,
            'msg_resultado', format('El expediente cuenta con %s documento(s) obligatorio(s) pendiente(s) o vencido(s).', jsonb_array_length(v_faltantes)),
            'error', -1,
            'valido', false,
            'mensaje', format('El expediente cuenta con %s documento(s) obligatorio(s) pendiente(s) o vencido(s).', jsonb_array_length(v_faltantes)),
            'faltantes', v_faltantes,
            'data', jsonb_build_object(
                'ag_id', v_ag.ag_id,
                'folio', v_ag.folio,
                'procedimiento_codigo', v_proc_canonico,
                'procedimiento_nombre', v_proc_nombre,
                'importe_total_pago', v_ag.importe_total_pago,
                'valido', false,
                'total_obligatorios', v_total_obligatorios,
                'cumplidos_obligatorios', v_cumplidos_obligatorios,
                'faltantes', v_faltantes,
                'alertas_condicionales', v_alertas,
                'items', v_items
            )
        );
    END IF;

    RETURN jsonb_build_object(
        'cod_resultado', 0,
        'msg_resultado', 'Expediente documental íntegro y verificado correctamente.',
        'error', 0,
        'valido', true,
        'mensaje', 'Expediente documental íntegro y verificado correctamente.',
        'faltantes', '[]'::jsonb,
        'data', jsonb_build_object(
            'ag_id', v_ag.ag_id,
            'folio', v_ag.folio,
            'procedimiento_codigo', v_proc_canonico,
            'procedimiento_nombre', v_proc_nombre,
            'importe_total_pago', v_ag.importe_total_pago,
            'valido', true,
            'total_obligatorios', v_total_obligatorios,
            'cumplidos_obligatorios', v_cumplidos_obligatorios,
            'faltantes', '[]'::jsonb,
            'alertas_condicionales', v_alertas,
            'items', v_items
        )
    );
END;

El alta requiere doc_codigo. La escritura requiere doc_nombre y formato_permitido. Los renglones de procedimientos reciben procedimiento_codigo, nivel_exigencia y, cuando apliquen, condicion_sql y orden_visual. El usuario de auditoría se obtiene de la sesión autenticada.

Las respuestas de negocio conservan cod_resultado, msg_resultado y data, además de los alias heredados. Los guards y los validadores de parámetros y cuerpos pueden rechazar la petición antes de invocar el servicio.

Trazabilidad para minería de procesos

La transición exitosa se escribe en cxp.afectaciones_historial con UUID de afectación, ejercicio, acción, estados, usuario y fechas. El intento rechazado por el checklist retorna antes de esa escritura.

La propuesta de registro transversal de eventos contempla una función genérica para actividades formales. Para este módulo, los puntos candidatos son una revisión documental formal y el resultado de ENVIAR, correlacionados por UUID y ejercicio. El evento propuesto puede conservar actor, rol, fecha, estados, procedimiento y códigos faltantes. Las ediciones de catálogo se vincularían por doc_id como cambios de configuración.
