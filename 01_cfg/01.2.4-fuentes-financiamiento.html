01.2.4

Fuentes de Financiamiento

Catálogo normativo que identifica el origen y la naturaleza jurídica de los recursos presupuestarios del Poder Judicial del Estado de Veracruz (SEFIPLAN / CONAC / LDF).

Modo A — existe en código Ruta: cfg / catalogos / fuentesf Endpoint: /configuracion/fuentesf
1 Descripción General

El catálogo de Fuentes de Financiamiento clasifica los recursos públicos que ingresan y se ejercen en el Poder Judicial, permitiendo dar trazabilidad al origen de los fondos conforme a los lineamientos del CONAC y la Ley de Disciplina Financiera (LDF).

En la arquitectura del SIAF-PJEV, la fuente de financiamiento se gestiona mediante segmentos atómicos homologados con la Clave Presupuestal (02.1.1), permitiendo tanto su visualización en una clave resumen de 6 dígitos como su articulación jerárquica con el árbol de Ingresos bajo el rubro institucional 1180000 (Transferencias, Asignaciones y Donativos Corrientes Recibidos):

  • Segmentación Atómica Homologada:
    — cff_tipo_fondo (1 dígito): 1 = Estatal / Propios (No Etiquetado), 2 = Federal (Etiquetado).
    — cff_fondo_especifico (3 dígitos): 601 (Presupuesto Autorizado), 609 (Convenios), 701 (Recursos Propios), 702 (Fondo Auxiliar), 501 (FASP), 502 (Juzgados Laborales).
    — cff_anio (2 dígitos): Calculado automáticamente a partir del ejercicio fiscal vinculado (ej. 26 para 2026).
    — cff_tipo_gasto (1 dígito): Clasificador de gasto por defecto (1 = Corriente, 2 = Capital).
  • Clave Concatenada Resultante (6 dígitos): cff_clave = [tipo_fondo][fondo_especifico][anio] (Ej. 160126, 250126).
  • Segmento en Clave Presupuestal (7 dígitos): ...-[tipo_fondo]-[fondo_especifico]-[anio]-[tipo_gasto] (Ej. ...-1-601-26-1).
  • Subcuenta 1182001 (Federal): Fondos etiquetados provenientes del Gobierno Federal (Ej. 250126 FASP, 250226 JLAB).
  • Subcuenta 1182002 (Estatal): Subsidio estatal ordinario (160126), convenios (160926), recursos propios (170126) y fondo auxiliar (170226).

5 Procedimientos Almacenados (Stored Procedures)

Procedimientos transaccionales bajo esquema config, convención SECURITY DEFINER y contrato estándar JSONB { "cod_resultado": 0, "msg_resultado": "OK", "data": [...] }.

5.1. Procedimiento LEER (config.fn_fuentes_financiamiento_leer)

Consulta las fuentes de financiamiento del ejercicio fiscal, devolviendo tanto los campos atómicos homologados (cff_tipo_fondo, cff_fondo_especifico, cff_anio, cff_tipo_gasto) como la clave concatenada y metadatos de clasificación LDF.

Parámetro (IN)TipoDescripción
p_idINTID de la fuente (o NULL para listado general / bandeja).
p_busquedaVARCHARFiltro opcional por clave concatenada, nombre descriptivo o nemotécnico.
p_eje_idINTFiltro obligatorio por Ejercicio Fiscal (FK catalogo_ejercicios.eje_id).
p_tipo_fondoSMALLINTFiltro opcional por Tipo de Fondo (1 = Estatal/Propios, 2 = Federal).
p_estatusINT1 = Activos, 0 = Inactivos, NULL = Todos.
p_pageINTNúmero de página para paginación (default 1).
p_limitINTLímite de registros por página (default 20, máximo 100).
config.fn_fuentes_financiamiento_leer.sql PL/pgSQL 
CREATE OR REPLACE FUNCTION config.fn_fuentes_financiamiento_leer(
    p_id          INT      DEFAULT NULL,
    p_busqueda    VARCHAR  DEFAULT NULL,
    p_eje_id      INT      DEFAULT NULL,
    p_tipo_fondo  SMALLINT DEFAULT NULL,
    p_estatus     INT      DEFAULT 1,
    p_page        INT      DEFAULT 1,
    p_limit       INT      DEFAULT 20
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = config, presupuesto, public
AS $$
DECLARE
    v_offset INT;
    v_total  INT;
    v_data   JSONB;
BEGIN
    v_offset := (GREATEST(p_page, 1) - 1) * LEAST(GREATEST(p_limit, 1), 100);

    -- Conteo total para paginación
    SELECT COUNT(*) INTO v_total
    FROM config.catalogo_fuentes_fin ff
    WHERE (p_id IS NULL OR ff.cff_id = p_id)
      AND (p_eje_id IS NULL OR ff.cff_ejercicio = p_eje_id)
      AND (p_tipo_fondo IS NULL OR ff.cff_tipo_fondo = p_tipo_fondo)
      AND (p_estatus IS NULL OR ff.estatus_registro = p_estatus)
      AND (
          p_busqueda IS NULL OR
          ff.cff_clave ILIKE '%' || TRIM(p_busqueda) || '%' OR
          ff.cff_abrev ILIKE '%' || TRIM(p_busqueda) || '%' OR
          ff.cff_nombre ILIKE '%' || TRIM(p_busqueda) || '%'
      );

    -- Recuperación de registros con formato enriquecido
    SELECT COALESCE(jsonb_agg(
        jsonb_build_object(
            'id',                  ff.cff_id,
            'ejercicioId',         ff.cff_ejercicio,
            'ejercicioAnio',       ce.eje_anio,
            'tipoFondo',           ff.cff_tipo_fondo,
            'fondoEspecifico',     ff.cff_fondo_especifico,
            'anio',                ff.cff_anio,
            'tipoGasto',           ff.cff_tipo_gasto,
            'tipoGastoLabel',      CASE WHEN ff.cff_tipo_gasto = 2 THEN 'Capital' ELSE 'Corriente' END,
            'clave',               ff.cff_clave,
            'abrev',               ff.cff_abrev,
            'nombre',              ff.cff_nombre,
            'descripcion',         ff.cff_descripcion,
            'tipo',                ff.cff_tipo,
            'tipoLabel',           CASE ff.cff_tipo
                                       WHEN 1 THEN 'Estatal'
                                       WHEN 2 THEN 'Federal'
                                       WHEN 3 THEN 'Propios'
                                       WHEN 4 THEN 'Concentradora'
                                       ELSE 'Desconocido'
                                   END,
            'regimenLdf',          CASE WHEN ff.cff_tipo_fondo = 2 THEN 'Etiquetado Federal' ELSE 'No Etiquetado' END,
            'concentradora',       ff.cff_concentradora,
            'estatus',             ff.estatus_registro,
            'fechaCreacion',       ff.fecha_c,
            'usuarioCreacion',     ff.usuario_c
        )
    ), '[]'::jsonb) INTO v_data
    FROM config.catalogo_fuentes_fin ff
    LEFT JOIN config.catalogo_ejercicios ce ON ce.eje_id = ff.cff_ejercicio
    WHERE (p_id IS NULL OR ff.cff_id = p_id)
      AND (p_eje_id IS NULL OR ff.cff_ejercicio = p_eje_id)
      AND (p_tipo_fondo IS NULL OR ff.cff_tipo_fondo = p_tipo_fondo)
      AND (p_estatus IS NULL OR ff.estatus_registro = p_estatus)
      AND (
          p_busqueda IS NULL OR
          ff.cff_clave ILIKE '%' || TRIM(p_busqueda) || '%' OR
          ff.cff_abrev ILIKE '%' || TRIM(p_busqueda) || '%' OR
          ff.cff_nombre ILIKE '%' || TRIM(p_busqueda) || '%'
      )
    ORDER BY ff.cff_ejercicio DESC, ff.cff_clave ASC
    OFFSET v_offset
    LIMIT LEAST(GREATEST(p_limit, 1), 100);

    RETURN jsonb_build_object(
        'cod_resultado', 0,
        'msg_resultado', 'Consulta ejecutada exitosamente',
        'total',         v_total,
        'pagina',        p_page,
        'data',          v_data
    );
END;
$$;

5.2. Procedimiento ABC (config.fn_fuentes_financiamiento_abc)

Control transaccional para Alta (1), Cambio (2) y Baja Lógica (3). Realiza el cálculo automático de cff_anio a partir de catalogo_ejercicios.eje_anio, ensambla la cff_clave concatenada y valida la integridad presupuestal antes de cualquier modificación o baja.

Parámetro (IN)TipoDescripción / Validación
p_accionSMALLINT1 = Alta, 2 = Modificación, 3 = Baja Lógica (estatus=0).
p_idINTID de la fuente (NULL en Alta, obligatorio en Cambio y Baja).
p_ejercicio_idINTID del Ejercicio Fiscal (FK catalogo_ejercicios.eje_id).
p_tipo_fondoSMALLINT1 = Estatal / Propios (No Etiquetado), 2 = Federal (Etiquetado).
p_fondo_especificoVARCHAR(3)3 dígitos exactos del fondo (ej. 601, 702, 501).
p_tipo_gastoSMALLINTClasificador de gasto aplicable (1 = Corriente, 2 = Capital).
p_abrevVARCHAR(5)Abreviatura institucional en mayúsculas (ej. EST, FASP).
p_nombreVARCHAR(150)Denominación formal completa del fondo.
p_descripcionVARCHAR(300)Descripción opcional o justificación normativa.
p_tipoSMALLINTTipo institucional (1=Estatal, 2=Federal, 3=Propios, 4=Concentradora).
p_concentradoraSMALLINTIndicador de cuenta concentradora (0 = No, 1 = Sí).
p_usuario_idVARCHAR(20)Identificador del usuario operador para la bitácora de auditoría.
config.fn_fuentes_financiamiento_abc.sql PL/pgSQL 
CREATE OR REPLACE FUNCTION config.fn_fuentes_financiamiento_abc(
    p_accion            SMALLINT,
    p_id                INT          DEFAULT NULL,
    p_ejercicio_id      INT          DEFAULT NULL,
    p_tipo_fondo        SMALLINT     DEFAULT NULL,
    p_fondo_especifico  VARCHAR(3)   DEFAULT NULL,
    p_tipo_gasto        SMALLINT     DEFAULT 1,
    p_abrev             VARCHAR(5)   DEFAULT NULL,
    p_nombre            VARCHAR(150) DEFAULT NULL,
    p_descripcion       VARCHAR(300) DEFAULT NULL,
    p_tipo              SMALLINT     DEFAULT 1,
    p_concentradora     SMALLINT     DEFAULT 0,
    p_usuario_id        VARCHAR(20)  DEFAULT 'SISTEMA'
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = config, presupuesto, public
AS $$
DECLARE
    v_eje_anio      INT;
    v_cff_anio      SMALLINT;
    v_clave_final   VARCHAR(10);
    v_fondo_esp     VARCHAR(3);
    v_abrev         VARCHAR(5);
    v_nuevo_id      INT;
    v_partidas_cnt  INT;
BEGIN
    -- ─────────────────────────────────────────────────────────────────
    -- 1. ACCIÓN 1: ALTA (CREACIÓN)
    -- ─────────────────────────────────────────────────────────────────
    IF p_accion = 1 THEN
        -- Validaciones iniciales
        IF p_ejercicio_id IS NULL THEN
            RETURN jsonb_build_object('cod_resultado', 400, 'msg_resultado', 'El ejercicio fiscal es obligatorio');
        END IF;

        -- Obtener año fiscal del ejercicio
        SELECT eje_anio INTO v_eje_anio
        FROM config.catalogo_ejercicios
        WHERE eje_id = p_ejercicio_id;

        IF NOT FOUND THEN
            RETURN jsonb_build_object('cod_resultado', 404, 'msg_resultado', 'El ejercicio fiscal especificado no existe');
        END IF;

        -- RN-02: Calcular cff_anio en 2 dígitos
        v_cff_anio := (v_eje_anio % 100)::SMALLINT;

        -- Normalizar fondo específico y abreviatura
        v_fondo_esp := UPPER(TRIM(COALESCE(p_fondo_especifico, '')));
        v_abrev     := UPPER(TRIM(COALESCE(p_abrev, '')));

        IF v_fondo_esp = '' OR LENGTH(v_fondo_esp) > 3 THEN
            RETURN jsonb_build_object('cod_resultado', 400, 'msg_resultado', 'El fondo específico debe tener de 1 a 3 caracteres alfanuméricos');
        END IF;

        -- RN-03: Ensamblar clave concatenada [tipo_fondo][fondo_especifico][anio]
        v_clave_final := COALESCE(p_tipo_fondo, 1)::TEXT || v_fondo_esp || LPAD(v_cff_anio::TEXT, 2, '0');

        -- RN-04: Validar unicidad de clave por ejercicio fiscal
        IF EXISTS (
            SELECT 1 FROM config.catalogo_fuentes_fin
            WHERE cff_clave = v_clave_final AND cff_ejercicio = p_ejercicio_id
        ) THEN
            RETURN jsonb_build_object(
                'cod_resultado', 409,
                'msg_resultado', 'RN-04: La clave concatenada ' || v_clave_final || ' ya existe para el ejercicio ' || v_eje_anio::TEXT
            );
        END IF;

        -- Insertar registro canónico
        INSERT INTO config.catalogo_fuentes_fin (
            cff_clave, cff_abrev, cff_nombre, cff_descripcion,
            cff_ejercicio, cff_tipo, cff_tipo_fondo, cff_fondo_especifico,
            cff_anio, cff_tipo_gasto, cff_concentradora,
            estatus_registro, usuario_c, fecha_c
        ) VALUES (
            v_clave_final, v_abrev, TRIM(p_nombre), TRIM(p_descripcion),
            p_ejercicio_id, COALESCE(p_tipo, 1), COALESCE(p_tipo_fondo, 1), v_fondo_esp,
            v_cff_anio, COALESCE(p_tipo_gasto, 1), COALESCE(p_concentradora, 0),
            1, p_usuario_id, NOW()
        ) RETURNING cff_id INTO v_nuevo_id;

        RETURN jsonb_build_object(
            'cod_resultado', 0,
            'msg_resultado', 'Fuente de financiamiento creada exitosamente',
            'data', jsonb_build_object(
                'id',              v_nuevo_id,
                'clave',           v_clave_final,
                'tipoFondo',       p_tipo_fondo,
                'fondoEspecifico', v_fondo_esp,
                'anio',            v_cff_anio
            )
        );

    -- ─────────────────────────────────────────────────────────────────
    -- 2. ACCIÓN 2: MODIFICACIÓN (CAMBIO)
    -- ─────────────────────────────────────────────────────────────────
    ELSIF p_accion = 2 THEN
        IF p_id IS NULL THEN
            RETURN jsonb_build_object('cod_resultado', 400, 'msg_resultado', 'El ID de la fuente es obligatorio para modificar');
        END IF;

        -- Recuperar ejercicio si no viene dado
        IF p_ejercicio_id IS NOT NULL THEN
            SELECT eje_anio INTO v_eje_anio FROM config.catalogo_ejercicios WHERE eje_id = p_ejercicio_id;
            v_cff_anio := (v_eje_anio % 100)::SMALLINT;
        ELSE
            SELECT ff.cff_anio INTO v_cff_anio FROM config.catalogo_fuentes_fin ff WHERE ff.cff_id = p_id;
        END IF;

        IF p_fondo_especifico IS NOT NULL THEN
            v_fondo_esp := UPPER(TRIM(p_fondo_especifico));
            v_clave_final := COALESCE(p_tipo_fondo, 1)::TEXT || v_fondo_esp || LPAD(v_cff_anio::TEXT, 2, '0');

            -- Validar unicidad excluyendo el registro actual
            IF EXISTS (
                SELECT 1 FROM config.catalogo_fuentes_fin
                WHERE cff_clave = v_clave_final
                  AND cff_ejercicio = COALESCE(p_ejercicio_id, cff_ejercicio)
                  AND cff_id <> p_id
            ) THEN
                RETURN jsonb_build_object('cod_resultado', 409, 'msg_resultado', 'RN-04: La clave resultante ya está asignada a otra fuente');
            END IF;
        END IF;

        UPDATE config.catalogo_fuentes_fin
        SET
            cff_clave            = COALESCE(v_clave_final, cff_clave),
            cff_abrev            = COALESCE(UPPER(TRIM(p_abrev)), cff_abrev),
            cff_nombre           = COALESCE(TRIM(p_nombre), cff_nombre),
            cff_descripcion      = COALESCE(TRIM(p_descripcion), cff_descripcion),
            cff_ejercicio        = COALESCE(p_ejercicio_id, cff_ejercicio),
            cff_tipo             = COALESCE(p_tipo, cff_tipo),
            cff_tipo_fondo       = COALESCE(p_tipo_fondo, cff_tipo_fondo),
            cff_fondo_especifico = COALESCE(v_fondo_esp, cff_fondo_especifico),
            cff_anio             = COALESCE(v_cff_anio, cff_anio),
            cff_tipo_gasto       = COALESCE(p_tipo_gasto, cff_tipo_gasto),
            cff_concentradora    = COALESCE(p_concentradora, cff_concentradora),
            usuario_m            = p_usuario_id,
            fecha_m              = NOW()
        WHERE cff_id = p_id;

        RETURN jsonb_build_object('cod_resultado', 0, 'msg_resultado', 'Fuente modificada exitosamente');

    -- ─────────────────────────────────────────────────────────────────
    -- 3. ACCIÓN 3: BAJA LÓGICA (INACTIVACIÓN)
    -- ─────────────────────────────────────────────────────────────────
    ELSIF p_accion = 3 THEN
        IF p_id IS NULL THEN
            RETURN jsonb_build_object('cod_resultado', 400, 'msg_resultado', 'El ID de la fuente es obligatorio para inactivar');
        END IF;

        -- RN-05: Validar que no tenga afectaciones presupuestales vigentes
        SELECT COUNT(*) INTO v_partidas_cnt
        FROM cxp.afectaciones_gasto_partidas agp
        WHERE agp.f_fuente_fin_id = p_id AND agp.estatus_registro = 1;

        IF v_partidas_cnt > 0 THEN
            RETURN jsonb_build_object(
                'cod_resultado', 409,
                'msg_resultado', 'RN-05: No se puede inactivar la fuente porque cuenta con partidas o afectaciones vigentes'
            );
        END IF;

        -- RN-06: Aplicar baja lógica
        UPDATE config.catalogo_fuentes_fin
        SET estatus_registro = 0,
            usuario_m        = p_usuario_id,
            fecha_m          = NOW()
        WHERE cff_id = p_id;

        RETURN jsonb_build_object('cod_resultado', 0, 'msg_resultado', 'Fuente inactivada correctamente');

    ELSE
        RETURN jsonb_build_object('cod_resultado', 400, 'msg_resultado', 'Acción inválida. Use 1 (Alta), 2 (Cambio) o 3 (Baja)');
    END IF;

EXCEPTION WHEN OTHERS THEN
    RETURN jsonb_build_object(
        'cod_resultado', 500,
        'msg_resultado', 'Error interno en base de datos: ' || SQLERRM
    );
END;
$$;
