01.4.3

Conceptos de Movimientos Bancarios

Catálogo tipificador de transacciones bancarias (cargos, abonos, comisiones, rendimientos y transferencias SPEI) para la automatización de la conciliación bancaria y la generación de pólizas de egresos e ingresos.

Modo B — Catálogo Institucional Base Tipo: Análisis Funcional (DOC-08) CONAC: Conciliación 1.1.1.2
🔄 Automatización del Cuadre Contable-Bancario

Este catálogo permite mapear los códigos de operación que emiten los bancos en los extractos mensuales (layouts de Banorte y BBVA) para conciliar automáticamente transferencias SPEI de nómina, pagos a proveedores, intereses ganados e IVA por comisiones bancarias contra las subcuentas contables del COA.

1 Descripción General

El catálogo 01.4.3 Conceptos Bancarios clasifica la naturaleza de cada flujo monetario que afecta a las cuentas bancarias institucionales (01.4.2), distinguiendo entre Cargos (disminución del saldo por transferencias SPEI de pagos o comisiones) y Abonos (incrementos por depósitos de ministración, recaudación o intereses).

3 Procedimientos Almacenados (PostgreSQL)
CREATE OR REPLACE FUNCTION config.fn_leer_conceptos_bancarios(
    p_usuario VARCHAR,
    p_naturaleza VARCHAR DEFAULT NULL,
    p_solo_activos BOOLEAN DEFAULT TRUE
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = config, contabilidad, public
AS $$
DECLARE
    v_data JSONB;
BEGIN
    SELECT jsonb_agg(
        jsonb_build_object(
            'concepto_bancario_id', cb.concepto_bancario_id,
            'clave_concepto', cb.clave_concepto,
            'naturaleza', cb.naturaleza,
            'descripcion', cb.descripcion,
            'cuenta_contable_sugerida_id', cb.cuenta_contable_sugerida_id,
            'estatus_registro', cb.estatus_registro
        ) ORDER BY cb.naturaleza, cb.descripcion
    )
    INTO v_data
    FROM config.cat_conceptos_bancarios cb
    WHERE (NOT p_solo_activos OR cb.estatus_registro = 1)
      AND (p_naturaleza IS NULL OR cb.naturaleza = p_naturaleza);

    RETURN jsonb_build_object('error', 0, 'mensaje', 'Conceptos bancarios recuperados.', 'data', COALESCE(v_data, '[]'::jsonb));
END;
$$;
