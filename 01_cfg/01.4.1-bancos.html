01.4.1

Instituciones Bancarias (Bancos)

Catálogo maestro de Instituciones de Banca Múltiple reguladas por la Comisión Nacional Bancaria y de Valores (CNBV) y catalogadas por el Banco de México (Banxico) para la dispersión y validación de transferencias electrónicas interbancarias (SPEI / SPID).

Modo B — Catálogo Institucional Base Tipo: Análisis Funcional (DOC-08) Norma: Catálogo Banxico / SPEI
🏦 Fundamento SPEI y Validación de Primeros 3 Dígitos en CLABE

Cada institución bancaria posee una Clave Banxico oficial de 3 dígitos (ej. 012 BBVA, 072 Banorte, 014 Santander). Esta clave constituye los primeros 3 caracteres de las CLABEs interbancarias de 18 dígitos, permitiendo la validación sintáctica cruzada en el alta de cuentas institucionales y cuentas de beneficiarios.

1 Descripción General

El catálogo 01.4.1 Instituciones Bancarias centraliza el directorio de bancos integrantes del Sistema de Pagos Electrónicos Interbancarios (SPEI). Es utilizado por:

  • 01.4.2 Cuentas Bancarias Institucionales: Para tipificar las cuentas ordenantes del PJEV.
  • 01.3.1 Proveedores y 01.3.3 Empleados: Para registrar las cuentas bancarias destino de abono en nómina y pagos de contratistas.

3 Procedimientos Almacenados (PostgreSQL)
CREATE OR REPLACE FUNCTION config.fn_leer_bancos(
    p_usuario VARCHAR,
    p_solo_activos BOOLEAN DEFAULT TRUE
)
RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = config, public
AS $$
DECLARE
    v_data JSONB;
BEGIN
    SELECT jsonb_agg(
        jsonb_build_object(
            'banco_id', banco_id,
            'nombre_banco', nombre_banco,
            'clave_banxico', clave_banxico,
            'nombre_corto', nombre_corto,
            'estatus_registro', estatus_registro
        ) ORDER BY nombre_corto
    )
    INTO v_data
    FROM config.cat_bancos
    WHERE (NOT p_solo_activos OR estatus_registro = 1);

    RETURN jsonb_build_object('error', 0, 'mensaje', 'Bancos recuperados.', 'data', COALESCE(v_data, '[]'::jsonb));
END;
$$;
